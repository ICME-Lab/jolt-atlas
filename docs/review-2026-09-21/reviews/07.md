# Reduce native verification and checked decoding cost

Native verification repeatedly combines group elements, searches opening lists performs expensive checked decoding in the pairing target group (GT), and retains temporary witness data. This change adds group multiscalar multiplication (MSM), indexed opening membership, checked compact encoding and shorter subgroup checks, and releases data after its last use. Transcript order and rejection behavior are preserved.

**Topic** native verifier and transport. **Type** Performance and new transport with equivalent validation predicates. **Planned PR target** `main`. **Prerequisite** [the held native prover branch](https://github.com/ICME-Lab/jolt-atlas/tree/review/native-prover).

The branch records the merged main history with an identical source tree to tested head `2e415e2a8bfd71678b7b62766a149b259dc166ce`. Its prerequisite changes remain part of the comparison with main until merged.

## Implementation and review examples

The opening index preserves insertion and transcript order while replacing repeated linear membership searches. Group MSM and parallel combinations retain the same group result. Compact GT decoding checks canonical fields and exact subgroup membership. Faster cyclotomic powering is used only after the required membership predicates succeed.

The storage change consumes completed stages and intermediate sparse rows, moves builder inputs, and removes witness-only retained copies from a distinct verifier wrapper. An independent oracle retains the original matrix construction. Matrix entries, variable order, aliases, commitments and transcript order stay identical.

Verification measurements use the same saved proof. Decode time, honest verification and validation including deliberate rejection trials are distinct scopes. The transport size in the table also includes an external codec, so the generic GT wrapper alone does not own that saving.
