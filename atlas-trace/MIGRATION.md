# Migrating `jolt-atlas-core` from `atlas-onnx-tracer` to `atlas-trace`

`atlas-trace` + `atlas-onnx-import` replace `atlas-onnx-tracer` end to end.
Validation status (differential suites in both crates' `tests/`):

- **Bit-exact against the old pipeline** on every model in the zoo —
  including GPT-2, Qwen (unpadded reference) and BGE — for identical inputs.
- **Qwen padded execution**: the old pipeline is *not padding-invariant*
  (its GQA repeat_kv reshape `[1,2,7,16,64]→[1,14,16,64]` scrambles when the
  7 pads to 8 — padded output differs from the true model, max diff ≈ 284k at
  scale 14). The new pipeline lowers repeat_kv to a padding-coherent head
  gather and is bit-exact padded vs unpadded. **The statement being proven
  for Qwen changes (to the correct one) at migration.**
- Two zoo fixtures (`slice`, `concat_transformer_block`) are rejected with
  typed errors; the old crate accepted them while producing trace tensors
  whose dims disagree with the declared padded dims.

## API surface mapping (prover side)

| Old (`atlas-onnx-tracer` / local prover code) | New |
|---|---|
| `Model::load(path, &RunArgs)` | `atlas_onnx_import::load(path, &LoadOptions) -> ImportedModel` |
| `ComputationGraph { nodes: BTreeMap, .. }` | `Graph { nodes: Vec<Node> }`; `NodeId` = dense index, topo order structural |
| `node.sat_clamp_bits: usize` | `NodeMeta.sat_clamp_bits: Option<ClampWidth>` (`.bits()`) |
| per-op `scale` fields | one `Model::scale()` (`Scale` newtype); ops carry `rebase: bool` where the raw variant exists |
| `rebase_bits` / `fuses_rebase` matches in `fused_rebase.rs` | `node.op.spec().rebase_divisor(scale)` |
| `{einsum,mul,square,cube}_intermediate_and_remainder`, `mos_*` imports | `Trace::fused(id)` (always captured), or re-run `node.op.spec().eval(operands, &ctx)` |
| `softmax_last_axis_decomposed` recomputation | `Trace::softmax(id)` — the full `SoftmaxWitness` is captured in the trace |
| `generate_exp_lut_decomposed(multiplier)` | `semantics::tables::exp_lut_decomposed(scale, SemVersion::V1)` |
| `materialize_signed_activation_table(.., nonlinearities::tanh)` etc. (f64) | `semantics::tables::table(TableKind::Tanh, scale, version)` — pure integer, golden-hashed |
| `EINSUM_REGISTRY` string aliases (26 patterns → 8 forms) | parsed `EinsumEq`; the importer emits only `{mk,kn | mk,nk}`, `{amk,akn | amk,ank}`, `{abmk,abkn | abmk,abnk}` (full-letter equations, no dropped letters) |
| `common::consts::{TRIG_PERIOD_MODULUS, TRIG_DOWNSCALE_BITS}` | `semantics::fixed::{trig_period_modulus, trig_downscale_bits}` |
| `Tensor.inner` public field | `Tensor::data()` / `into_data()`; `padded_next_power_of_two()` → `padded_pow2()` |
| implicit input conventions (hand-scaled masks/positions in examples) | `ImportedModel::input_descriptors` (`RawInt` vs `Scaled`) + `InputDescriptor::quantize_f64` |

## Proof-spec changes to coordinate (one `SemVersion` bump at migration)

1. **Deterministic activation tables**: entries may differ from the old
   f64-generated tables by one ulp on rounding ties (measured: zero diffs on
   all zoo traffic). Tables are generated by `semantics::tables` — pure
   integer, versioned, pinned by FNV golden hashes in
   `atlas-trace/tests/golden_tables.rs`.
2. **Softmax padding mask**: `SoftmaxLastAxis.active_len` masks padded
   lanes (old behavior corrupted padded rows). The softmax sumchecks gain
   one public selector polynomial `[j < active_len]`; masked lanes have all
   witness values 0 and are excluded from `exp_sum_q`.
3. **Softmax witness in the trace**: `Trace::softmax(id)` replaces the
   prover-side recomputation path.
4. **Qwen GQA**: repeat_kv lowers to `MoveAxis → GatherSmall(dict 2) →
   MoveAxis` instead of a scrambling reshape; einsum layouts are the natural
   batched forms above rather than tract's grouped-weight layouts.

## Where things live

- `atlas-trace/src/semantics/` — the audit surface: every kernel the proof
  relies on, ≈900 lines, no floats, no rayon (CI-guarded).
- `atlas-trace/tests/differential.rs` — graph-level equivalence vs the old
  crate (exact class byte-identical incl. `FusedIntermediates` and clamp
  widths; table class ≤ 1 ulp).
- `atlas-onnx-import/tests/differential_zoo.rs` — end-to-end model zoo
  equivalence (`-- --ignored` to run; `differential_big_models` covers
  GPT-2/Qwen/BGE).
- `cargo run -p atlas-onnx-import --example dump_lowered_ops -- <model.onnx>
  [bindings…]` — the lowered op inventory + einsum equations of a model.
