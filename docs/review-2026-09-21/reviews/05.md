# Prove committed table access and greedy generation

Generation requires access to the original committed tables, exact selection rules, a first-maximum tie rule and a registered stopping condition. This change proves original-table access, integer division, masks and selection, then shifted greedy token choice and stopping over the original hidden tensors.

**Topic** native generation. **Type** New relations, witness hardening and a measured gather optimization. **Base** `review/native-operators` (review unit 4).

**Primary source PRs** [#330](https://github.com/ICME-Lab/jolt-atlas/pull/330), [#331](https://github.com/ICME-Lab/jolt-atlas/pull/331), [#332](https://github.com/ICME-Lab/jolt-atlas/pull/332), [#333](https://github.com/ICME-Lab/jolt-atlas/pull/333), [#334](https://github.com/ICME-Lab/jolt-atlas/pull/334), [#336](https://github.com/ICME-Lab/jolt-atlas/pull/336), [#339](https://github.com/ICME-Lab/jolt-atlas/pull/339).

## Review order

1. Original committed tables and exact division.
2. Projected row gathers and isolated measurements.
3. Integer masks and checked witness construction.
4. First maximum over logical prefixes.
5. Shifted token selection, end tokens and stopping.

## Implementation and review examples

Table access binds to the original committed table, including after row projection. The selection relation enforces the first maximum within the logical vocabulary. If indices 0 and 1 have equal maximum scores, selecting 1 must fail. Response shifting, end tokens, stopping and padding are constrained separately.

Selection alone does not establish model provenance. The caller also requires the accepted causal model execution and canonical tensor conversion proofs for the same hidden values.

## Measurement conditions

The gather comparison uses the same hidden values on a Xeon E5-2699 v3 with eight workers. Each configuration has two invocations sharing one setup, with alternating configuration order. Proving excludes witness construction and commitments; process peak includes setup, registration, both proofs and their initial verification. Proof size includes the statement. [Pinned measurements and source evidence](https://github.com/ICME-Lab/zkARc/blob/cc299bc/native-atlas/row-gathers.md).
