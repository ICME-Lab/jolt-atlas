# Fix padded tensor semantics and commitment execution

Padded reshape lowering can reorder real elements, finite masks can leave a masked score dominant, and nested commitment worker pools can exhaust the stack. This change preserves the intended tensor values, enforces the supported masking range and keeps commitment execution correct under nested parallel calls.

**Topic** correctness. **Type** Correctness and resource hardening. **Base** `main`.

**Source continuity** `perf/round-2` was squash-merged in [#288](https://github.com/ICME-Lab/jolt-atlas/pull/288). The branch now records that main history; its source tree remains identical to tested head `0b28a6baff0ee3bf499726c0d3e63d703f3b007b`.
