# Prove exact native tensor arithmetic and layouts

Tensor arithmetic must match integer rescaling, clamping, padding and floor-division semantics, not just a field equation. This change adds clamped add/subtract, sums and means, contractions, reciprocal square root, softmax, broadcasts, layouts, slices and concatenation with the original hidden commitments.

**Topic** native operators. **Type** New relations and integer-semantics corrections. **Base** `main`.

## Implementation and review examples

Review the integer constraints separately from the generic opening repair. An equation such as `7 = 3*1 + 4` does not prove quotient 1 when dividing by 3. The remainder must also be less than 3. Logical means use the registered count, so 896 meaningful values padded to 1,024 still divide by 896.

The generic opening repair handles public slice coordinates equal to zero. The shortcut previously divided by a vanishing equality factor when recovering a round endpoint. The repaired path computes that endpoint directly and checks the resulting polynomial against independent evaluation for both binding orders, Boolean coordinates and zero scale. This is a prover correctness repair; no forged-proof acceptance is asserted.

This extension gives graph edges their tensor shapes, restores the registered normalization example, and exercises scalar tensor boundaries. Rejection of uncommitted witnesses accompanies the constructor added in the following PR. It retains the public registration and boundary APIs from the foundation.
