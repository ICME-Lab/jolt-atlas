# Reduce ordinary verifier work and compact HyperKZG proofs

Ordinary verification rebuilds public tables and selectors, repeats commitment arithmetic, and carries redundant proof encoding. Serial consumers also inherit ONNX import and parallel-runtime dependencies. This change reuses deterministic verifier work, preserves serial iterator semantics, and adds a bounded optional encoding that restores the original canonical proof bytes.

**Topic** ordinary verifier and transport. **Type** Performance, portability and decoder hardening. **Base** `review/tensor-correctness` ([#369](https://github.com/ICME-Lab/jolt-atlas/pull/369), review unit 1).

## Implementation and review examples

The serial facade checks both lengths before constructing `zip_eq`, including empty/nonempty mismatches. Equal-length pairs and immediate rejection run under both feature configurations. ONNX-dependent fixtures are gated at their callers. Independent tensor, polynomial and proof tests remain available without ONNX import. Helpers added by round two also use the facade.

The optional affine multiscalar multiplication (MSM) and fixed tables retain explicit feature flags. The default HyperKZG combination uses the shared MSM implementation. The compact decoder checks bounds and reconstructs the canonical proof bytes.

## Measurement conditions

The activation-cache and optional fixed-table results use the same saved Qwen proof, Rust 1.95, release overflow checks and inline Blake2. The fixed-table control already includes the activation cache; its validation guest is separate from the measured optimized guest. The #309 comparison isolates caching; #311 then isolates embedded tables. Both measure executed guest cycles.
